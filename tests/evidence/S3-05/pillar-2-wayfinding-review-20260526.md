- Screenshot iteration: the first Phase 4 capture used a 105-degree, elevated, tilted/yawed camera that read as an oblique scout view rather than player perspective. The capture runner was revised to 70-degree FOV, 0.7 m eye-height offset above `ClericShellMarker`, and straight `Vector3.back` view direction before this verdict was recorded.

The builder's mechanical sightline check confirms both Caretaker Hall and Court Vendor Hall are inside the spawn forward cone, but the player-perspective PNG does not strongly reinforce the second landmark visually.
- AC-11 walkthrough follow-up: the walkthrough log should confirm whether the landmark set reads better in motion and whether the spawn-to-Caretaker discovery feels like spatial reading rather than a guided route.
- Phase 8 verification follow-up: closure `verification.md` should document both the PASS WITH CONCERNS verdict and the color-space / lighting readability observation. It should also carry forward the recurring Unity batchmode ProjectSettings drift observed during Phase 4.
