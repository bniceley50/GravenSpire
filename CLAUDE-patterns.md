# CLAUDE-patterns.md — Cross-Cutting Patterns

Promoted from `tasks/lessons.md` when a lesson repeats or applies across
multiple subsystems. Path-scoped patterns go in `.claude/rules/*.md` instead.

This file is **not a catch-all.** If a pattern fits a single file type or
directory, it belongs in `.claude/rules/`. If it fits a single system, it
belongs in the system's GDD or ADR. `CLAUDE-patterns.md` is reserved for the
actual cross-cutters — rules that span 3+ systems or 2+ tiers.
